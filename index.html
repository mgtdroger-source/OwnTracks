TD Tour OwnTracks Setup

Select your phone.

TD Tour OwnTracks – Android

Tap below to apply the Tour tracking configuration.

Configure OwnTracks

Import the configuration

  1. OwnTracks opens the Import page.
  2. Select the tick at the top right.
  3. The Import page can then be closed.

Complete your setup

  1. Open OwnTracks.
  2. Select the three lines at the top left.
  3. Select Connection.
  4. Select Device ID and enter the entrant/driver surname.
  5. Select Tracker ID and enter your Tour/Rally number.

Start and stop tracking

The configuration leaves OwnTracks in Quiet.

▶
Move
White right-pointing triangle = tracking on.
■
Quiet
White square = tracking off.

Select the top toolbar icon, second from the right. Choose Move to start and Quiet to stop.

TD Tour OwnTracks – iPhone / iOS

Tap below to apply the Tour tracking configuration.

Configure OwnTracks

Import the configuration

  1. OwnTracks opens the Import page.
  2. Select the tick at the top right.
  3. The Import page can then be closed.

Complete your setup

  1. Open OwnTracks and open Settings.
  2. Check that Mode is HTTP.
  3. Check that URL contains the TD Tour tracking address.
  4. Select TrackerID and enter your Tour/Rally number.
  5. Select DeviceID and enter the entrant/driver surname.

Start and stop tracking

The tracking modes are shown as faint buttons across the top of the map:

Quiet   |   Manual   |   Significant   |   Move

  1. Select Move to start Tour tracking.
  2. Select Quiet to stop Tour tracking.

The configuration leaves OwnTracks in Quiet so tracking does not start before the event.
