TD Tour Traccar Setup

Select your phone.

TD Tour Traccar – Android

Install Traccar Client from Google Play, then tap the button below.

Configure Traccar

After configuration

  1. Open Traccar Client.
  2. Set Device identifier to Tour/Rally number followed by surname, for example 87 Smith.
  3. Check:
    • Server URL = TD Tour relay
    • Location accuracy = High
    • Distance = 500 m
    • Stationary heartbeat = 1800 s (30 minutes)
  4. Under Advanced settings, the configuration sets:
    • Offline buffering = Off
    • Wake lock = Off
    • Stop detection = Off
    Leave Use system location at the setting selected by Traccar for the device.
  5. Turn on Continuous tracking at the start of the Tour day.
  6. Turn off Continuous tracking at the end of the Tour day.

The Configure Traccar button applies the Tour tracking settings automatically. Enter the Device identifier as shown above, then start Continuous tracking on the Tour day.

TD Tour Traccar – iPhone / iOS

Install Traccar Client from the App Store, then apply the settings below.

1. Copy the Server URL

https://traccar-relay-test.mgtdroger.workers.dev/

2. Traccar settings

  1. Device identifier = Tour/Rally number followed by surname, for example 87 Smith.
  2. Server URL = paste the copied TD Tour relay URL.
  3. Location accuracy = High.
  4. Distance = 500 m.
  5. Stationary heartbeat = 1800 s (30 minutes).
  6. Offline buffering = Off.
  7. Stop detection = Off.
  8. Turn on Continuous tracking at the start of the Tour day.
  9. Turn it off at the end of the Tour day.
iPhone / iOS: setup is manual. Copy the Server URL above, then enter the settings exactly as listed.
