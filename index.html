TD Tour OwnTracks Setup

Select your phone.

TD Tour OwnTracks – Android

Tap below to apply the Tour tracking configuration.

Configure OwnTracks

Import the configuration

  1. OwnTracks opens the Import page.
  2. Select the tick at the top right to apply the configuration.
  3. The Import page can then be closed.

Complete your setup

  1. Open OwnTracks.
  2. Select the three lines at the top left.
  3. Select Connection.
  4. Select Device ID and enter the entrant/driver surname.
  5. Select Tracker ID and enter your Tour/Rally number.

Start and stop tracking

After configuration, OwnTracks is set to Quiet so tracking does not start before the event.

▶
Move
White right-pointing triangle on the blue top bar = tracking on.
■
Quiet
White square on the blue top bar = tracking off.

To change tracking mode, select the top toolbar icon, second from the right.

Select Move to start tracking. Select Quiet to stop tracking.

TD Tour OwnTracks – iPhone / iOS

Tap below to apply the Tour tracking configuration.

Configure OwnTracks

Import the configuration

  1. OwnTracks opens the Import page.
  2. Select the tick at the top right to apply the configuration.
  3. The Import page can then be closed.

Complete your setup

  1. Open OwnTracks and open Settings.
  2. Set Mode to HTTP.
  3. Select TrackerID and enter your Tour/Rally number.
  4. Select DeviceID and enter the entrant/driver surname.
  5. Check that URL contains the TD Tour tracking address supplied by the configuration.

Start and stop tracking

  1. To start tracking, select the i icon and choose Move.
  2. To stop tracking, select the i icon again and choose Quiet.

Move is the intended Tour tracking mode. Quiet stops tracking.
