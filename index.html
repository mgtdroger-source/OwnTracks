TD Tour OwnTracks Setup

Tap below to apply the Tour tracking configuration.

Configure OwnTracks

Import the configuration

  1. OwnTracks opens the Import page.
  2. Select the tick at the top right to apply the configuration.
  3. The Import page can then be closed.

Complete your setup

  1. Open OwnTracks.
  2. Select the three lines at the top left.
  3. Select Connection.
  4. Select Device ID and enter the entrant/driver surname.
  5. Select Tracker ID and enter your Tour/Rally number.

Start and stop tracking

After configuration, OwnTracks is set to Significant Changes.

▶
Significant Changes White right-pointing triangle on the blue top bar = tracking on.
■
Quiet White square on the blue top bar = tracking off.

To change tracking mode, select the top toolbar icon, second from the right.

Select Significant Changes to start tracking.

Select Quiet to stop tracking.

OwnTracks must already be installed.
